# Support

Use GitHub Issues for reproducible bugs and GitHub Discussions for protocol questions,
experiment interpretation, and ideas. Include the command, operating system, Python
version, and a synthetic reproduction.

Do not attach clinical data, screenshots containing patient information, case-level
predictions, internal paths, credentials, weights, or adapters. Report suspected
security or privacy problems privately as described in [SECURITY.md](SECURITY.md).

This is a research repository, not a medical service. No diagnosis or clinical-use
support is provided.
