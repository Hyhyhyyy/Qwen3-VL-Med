# R04–R07 形态—诊断拆分分析方法与空表

## 分析目的

将四个LoRA实验的完整报告指标拆成诊断、形态证据、安全代理和综合代理四层，回答冻结视觉、投影或语言模块后，性能变化主要发生在“看见并表达形态证据”还是“形成病理诊断”。

## 预注册对比

- 主基线：R04全组件LoRA。
- 配对对比：R05−R04、R06−R04、R07−R04。
- 分析单位：同一固定、去标识的私有测试病例集合；公开仓库不披露样本量。
- 区间：10,000次病例配对bootstrap的95%百分位区间。
- 方向：F1/recall/CRQS越高越好；遗漏、幻觉和矛盾代理率越低越好。

## 端点层级

1. 诊断：严格正确率、诊断概念F1。
2. 形态：临床事实F1、关键事实召回、实体F1代理、关系F1代理。
3. 安全代理：幻觉事实率、遗漏率、临床矛盾率。
4. 综合代理：CRQS-style proxy。

这些安全指标均来自参考文本规则抽取，不是阅片医师确认的图像基础临床终点。

## 当前产物

- `r04_r07_split_template.csv`：不含样本量和逐病例结果的公开结构模板。
- 真实逐例输入、置信区间中间量和人工核查记录只保存在批准的受控环境中。

最终解释必须以病例配对差值为主，并结合LoRA组件审计；不能仅凭非配对绝对分数推断模块因果作用。
