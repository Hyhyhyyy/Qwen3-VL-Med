## 状态定义

- **已完成并评测**：训练产物与统一评测结果均已完成内部验收。
- **训练完成**：最终模型或 Adapter 已完成内部验收，统一评测尚未完成或尚未归档。
- **原型/分支**：完成了数据或方法验证，不作为同口径主结果。
- **计划/暂缓**：设计已确定，但没有足够证据写成已完成实验。

## 跨阶段比较边界

1. 只有相同测试集、任务目标、解码设置与指标版本的 Run 才做直接数值比较。
2. R01 与 R02 的清洗集配对重评可以支持数据清洗结论；历史主表中不同 split 的数值不能直接排名。
3. MMBench 等公开通用基准只有在相同底座、提示、数据版本和解析规则下才能比较 alignment tax。
4. 点估计排序不等于显著差异；诊断结论需同时查看病例配对检验与置信区间。
