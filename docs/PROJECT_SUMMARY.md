# 项目总结（公开表达版）

围绕Qwen3-VL医疗多模态报告与诊断生成，完成从数据审计、严格清洗、病例级多图/单图/证据级任务构建，到Full SFT、LoRA、视觉塔/投影器/语言主干冻结消融和多GPU训练的端到端实验体系；建立可复用的13项统一评测流水线，覆盖文本与语义生成、严格诊断匹配、bootstrap置信区间、校准、视觉梯度/注意力、公开通用基准和医学文本嵌入相似度，并配套病例配对统计、自动验收、训练后评测、故障恢复、产物哈希和隐私发布门禁。实验表明数据质量与任务定义比单纯扩大可训练参数更关键，固定冻结视觉塔能在保持报告能力的同时减少通用遗忘，冻结投影器的双侧LoRA形成参数高效Pareto候选；Oracle/生成证据混合训练显著改善真实级联诊断，进一步明确了Oracle上限与Pipeline实效的边界。工程已将解释性协议升级为完整token×视觉token float16矩阵、逐head数据、patch空间映射、manifest和论文热图，并坚持所有临床原始产物只留在受控环境。
