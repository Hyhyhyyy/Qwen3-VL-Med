# 项目总结（公开表达版）

围绕 Qwen3-VL 医疗多模态报告生成，完成从数据审计、严格清洗、病例级多图与单图/证据级任务构建，到 Full SFT、LoRA、视觉塔/投影器/语言主干冻结消融和多 GPU 训练的端到端实验体系；建立可复用的 13 项统一评测流水线，覆盖文本与语义生成、严格诊断匹配、bootstrap 置信区间、校准、视觉梯度/注意力、公开通用基准和医学文本嵌入相似度，并配套病例配对统计、自动验收、训练后评测、故障恢复、产物哈希和隐私发布门禁。实验表明数据质量与任务定义比单纯扩大可训练参数更关键，语言侧适配不可缺失，冻结预训练跨模态投影器在两轮对照中表现出更好的医疗能力—通用能力 Pareto 趋势；同时明确了自动文本指标、病例级归因标量与临床有效性之间的证据边界，并为下一阶段 token—图像 patch 级 Gradient × Attention 热图归档制定了可复现协议。
